# Libro Epidemiología: Nivel Avanzado

## Sobre este libro

El propósito de este manual es proveer el material teórico y ejemplos prácticos a utilizar durante el curso de posgrado "Epidemiología: Nivel Avanzado" dictado por el Instituto Nacional de Epidemiología "Dr. Juan H. Jara", Mar del Plata Argentina.
