## 📖 Sobre este libro

El propósito de este manual es proveer el material teórico y los ejemplos prácticos aplicados que se utilizan durante el desarrollo del curso de posgrado **"Epidemiología: Nivel Avanzado"**, dictado por el Instituto Nacional de Epidemiología "Dr. Juan H. Jara" (Mar del Plata, Argentina). El material combina fundamentos metodológicos en epidemiología y modelado estadístico con flujos de trabajo prácticos en el lenguaje de programación R, utilizando herramientas modernas del ecosistema \`tidyverse\`.
